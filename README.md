# Reels Counter

A lightweight Android app for tracking and visualizing reel/session counts with a lock screen and widget-style stats experience.

## Features
- Track reel counter stats during usage
- Visual dashboard for activity trends
- Lock screen flow for quick interactions
- Widget support for quick stats visibility
- Accessibility service integration for counting interactions

## Requirements
- Android Studio Ladybug or newer
- JDK 17
- Android SDK 34
- Gradle 8.9
